# Лабораторна робота №1: Сучасні можливості Java та Data-Oriented Programming (DOP)

## Опис проєкту
Проєкт реалізує предметну модель та сервіс обробки фінансових транзакцій. Використовуються сучасні можливості Java:
- `sealed interface` та `record` для незмінної ієрархії даних.
- Вичерпний `switch expression` з `pattern matching.
- Текстові блоки (`Text Blocks`) для форматування виводу.
- Валідація у конструкторах `record`.

## Розрахунок варіанта
Варіант розраховується за формулою: $V = N \text{ mod } 3$.
Для номера $N = 10$: $10 \text{ mod } 3 = 1$ (**Фінансова система транзакцій**).
